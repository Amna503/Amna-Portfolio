## About

A modern, responsive portfolio website showcasing my projects, skills, and experience as a **BS Information Technology** student at the **University of Agriculture Faisalabad**. Built with clean HTML, CSS, and vanilla JavaScript — no frameworks, just craft.

## Features

- **Responsive Design** — Seamlessly adapts from mobile to desktop
- **Dark Theme** — Modern dark UI with gradient accents
- **Custom Cursor** — Interactive cursor with glow and magnetic button effects
- **Typing Animation** — Dynamic hero section with rotating titles
- **Smooth Scroll Navigation** — Active link highlighting on scroll
- **Particle Effects** — Subtle animated particles in the hero section
- **Scroll Reveal Animations** — Staggered fade-in animations for content sections
- **Contact Form** — Functional contact form powered by Formspree
- **Back to Top Button** — Smooth scroll-to-top on long pages
- **SEO Optimized** — Meta tags, Open Graph, and semantic HTML

## Getting Started

### Prerequisites

- A modern web browser
- [Git](https://git-scm.com/) installed

### Installation

```bash
# Clone the repository
git clone https://github.com/Amna503/Amna-Portfolio.git

# Navigate to the project
cd Amna-Portfolio

# Open in browser
start index.html
```

No build step required — it's a static site. Just open `index.html` in your browser.

## Deployment

This site is deployed on **Vercel**. Every push to `main` triggers an automatic deployment.

To deploy your own fork:

1. Fork this repository
2. Go to [vercel.com](https://vercel.com) → Import Project
3. Select your forked repo
4. Click **Deploy**
